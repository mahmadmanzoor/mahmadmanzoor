## 🧑‍💻 What I'm doing

- 🏗️ At **RipeSeed** I build quote-to-order workflows for an AI-enabled B2B roofing platform with Next.js, Django REST, PostgreSQL and AWS.
- 🤖 I build **OpenAI / Gemini PDF extraction pipelines** that turn roof reports into structured measurements, with confidence scoring and manual review.
- 📊 I work on executive analytics, platform-wide audit logging and AI workflow automation (background jobs, tracing, retries).
- 🏥 I also contribute to a multi-tenant healthcare platform for skilled nursing facilities (Next.js + FastAPI, OCR/LLM extraction).
- 🎓 BS Software Engineering, NUST, 2019–2023.
- 🎮 Fun fact: I love video games, so [my portfolio](https://mahmadmanzoor.com) is one.
